LineFollower — 10 physical tuning shapes (20 mm line)

Preview only. SVG files are true 1:1 millimetre scale — print at 100% / actual size.

1. S1 - Straight 1000 mm

1000 mm path · 1 runs · canvas 1120×200 mm

Tunes: Sensor weight symmetry, base_speed, steering PID (KP_L/KI_L/KD_L) straight-line damping

How: Place the robot centred on the line and let it run. Watch for (a) it veering consistently to one side -> weight asymmetry, (b) slow weaving -> KP_L too high or KD_L too low, (c) sluggish correction -> KP_L too low.

SVG · DXF

2. S2 - Square loop 200 mm (4 x 90 deg)

800 mm path · 4 runs · canvas 320×320 mm

Tunes: 90 deg turn rate (current_exit_ms / turn table), corner detection threshold

How: Run the loop repeatedly in one direction. If it cuts the corner, increase the turn duration; if it overshoots and has to come back, decrease it. Both left and right corners must behave the same -> that is a symmetry check on weights 1..14.

SVG · DXF

3. S3 - Open 3-turn Z (3 x 90 deg, 200 mm legs)

800 mm path · 5 runs · canvas 720×320 mm

Tunes: Turn direction reversal, turn-table slots, acceleration limit into/out of turns

How: Each corner alternates left/right. If only one direction misbehaves, the fault is in the turn table symmetry, not in speed. Watch the transition: the robot should slow, rotate, then reacquire without hunting.

SVG · DXF

4. S4 - Square 300 mm legs (high-speed corner entry)

1200 mm path · 4 runs · canvas 420×420 mm

Tunes: Acceleration limit / deceleration distance before a turn

How: Same 90 deg corner as S2 but with 300 mm to build speed. If the robot runs wide here but is fine on S2, the acceleration limit is too high or braking starts too late. Set the accel limit on this shape, then re-check S2.

SVG · DXF

5. S5 - Chamfered square (4 x 45 deg)

786 mm path · 6 runs · canvas 400×400 mm

Tunes: Outer sensor weights (w1, w14), FORCE_ERROR_MAG, 45 deg handling

How: At 45 deg two sensors go black almost simultaneously. If the robot stutters or loses the line here but is fine on S2, the outer weights are wrong. This is the shape that justifies ML-tuned weights.

SVG · DXF

6. S6 - Quarter arc R=200 mm (90 deg continuous)

314 mm path · 28 runs · canvas 450×450 mm

Tunes: Steering integral (KI_L) on a sustained error, continuous tracking

How: On a constant-radius arc the error is non-zero for a long time. Too little KI_L leaves a steady inward bias; too much winds up and the robot spirals off the end.

SVG · DXF

7. S7 - S-curve (2 x 200 mm arcs, reversed)

502 mm path · 56 runs · canvas 440×280 mm

Tunes: Integral windup (KI_L), reversal symmetry

How: Watch the second half. If the robot swings wide coming out of the first arc and takes time to settle, KI_L is winding up. Reduce it or clear the integral when the error sign flips.

SVG · DXF

8. S8 - Zigzag 120 mm legs (array straddles corners)

1080 mm path · 9 runs · canvas 840×240 mm

Tunes: Behaviour when the array cannot see a single clean line (line_found fallback)

How: 120 mm legs are shorter than the 130 mm array, so the array sees two line segments at once. If the robot loses the line only here, the problem is the fallback path, not the weights.

SVG · DXF

9. S9 - L-bend, 400 mm legs (single 90 deg, measurable)

800 mm path · 2 runs · canvas 520×520 mm

Tunes: Exact turn duration / turn-table slot for 90 deg (measure in ms)

How: One corner only, with 400 mm of straight either side. Time the rotation and check the exit: it should leave the corner parallel to the new line, not angled.

SVG · DXF

10. S10 - Rectangle 400 x 200 mm (race-style loop)

1200 mm path · 4 runs · canvas 520×320 mm

Tunes: End-to-end integration: all parameters together, lap timing

How: Run five laps and time them. This is the acceptance test: it should be clean and consistent. Use it to confirm whatever you changed on S1..S9 did not regress the whole system.

SVG · DXF

11. S11 - Stadium loop (continuous ML training, R=150 mm)

1742 mm path · 58 runs · canvas 820×420 mm

Tunes: Continuous lap-based ML training: endless labelled frames per loop

How: Run laps continuously with the 上位机 in labelling mode. Each lap streams frames through both straights and both arcs, so the MLP sees a full range of offsets and curvatures every lap. Vary the lateral offset slightly between laps to cover more of the input space.
