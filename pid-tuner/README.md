# PID 与 14 路传感器权重上位机

运行 `uv run --script app.py --open`，或使用 Python 3.10 以上安装 `requirements.txt` 后运行 `python app.py --open`。Mac 可双击 `启动上位机.command`；没有 uv 时需先准备 Python 与 PySerial。程序只监听 127.0.0.1，不上传车辆数据。

选择正确 USB 串口、115200 波特率，连接后点击“读取车端参数”或“读取权重”。灰色提示数字是源码默认参考，不是实际车端值。

- PID 和限幅参数可逐项或按组发送。速度环两轮共用 KP_L/KI_L/KD_L，固件中未使用的 KP_R/KI_R/KD_R 不在调节区。
- 14 路权重对应软件 S01–S14，命令为 weight1–weight14。取值 0–100，非负幅值；左右方向由原算法决定。外侧优先扫描保留，权重 0 不改变扫描优先级。
- 默认权重：6.5、5、4、3、2、1、0.1、0.1、1、2、3、4、5、6.5。
- 收到全部 14 路权重后才解锁输入。支持逐路或批量发送；所有设置只有车端回复后才标为确认，超时不代表生效。
- 参数草稿支持 JSON 保存/载入，包括权重。载入不会自动向车发送。可选择 profiles/2026-10-07-demo.json，它与固件开机默认值不同。
- 波形支持速度环、角速度环与 PWM 命令、时间窗、暂停显示和 CSV 导出。时间轴是电脑接收时间，当前约 15 Hz，并非完整 1 kHz 控制环记录。
- 14 路传感器遥测是二值状态，不能据此确认原始 ADC 幅值或已完成光学标定。
- 停车按钮发送 `!`，需观察车端回复和 PWM 归零；断开串口不会自动让车停止。

串口修改保存在 RAM，复位/断电后恢复源码默认值；传感器标定需要重新进行。CSV 保留最近最多 18000 帧，服务关闭后内存数据会消失，请及时导出。

新版主板默认巡航速度 40、关闭转向表；“临时停用转向表”按顺序将 turn1–turn20 置零，它不会改变角度表或 PID 算法。旧固件没有权重命令时，权重界面保持未就绪。

电脑侧无线 USB 接收器需要保持连接。ST-Link 与接收器可以同时接电脑；此前接回 ST-Link 时接收器消失，不能误判为两种通信必然冲突。不要让其他串口软件占用同一端口。

测试：`python -m unittest discover -s . -p 'test_*.py' -v`（POSIX 伪终端测试适用于 Mac/Linux）。Windows 上位机启动与硬件行为未在实机验证。
